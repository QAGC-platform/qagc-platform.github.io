# QAGC Platform — منصة ضمان الجودة

The platform of the Quality Assurance & Governance Centre (People with
Disabilities Sector). **This repository is the platform**: a single-file,
Arabic-first application served by GitHub Pages.

- **Live app (invited users):** https://qagc-platform.github.io/app/
- **Public root:** a deliberately blank green page — the uninvited learn nothing.
- **Privacy policy:** https://qagc-platform.github.io/privacy.html

## What it is

One HTML file — `app/index.html` — carrying the whole reviewed model:

- The 2027 annual plan (33 objectives) with three classification tags
- A single approval gate: approve / return with a written reason / refuse,
  two-step confirmation, stamped decisions, superior-first routing option
- KPIs with baselines, targets, tolerance bands, projections; Excel import,
  paste and round-trip; Word / PowerPoint / Excel export built in-page
- Leave absorbed whole, with balances that move
- The CPD programme: year board, month expansion, brochures, the eleven-phase
  organisation checklist, whole-event assignment
- Home-page engagement: DG broadcasts, ten-question polls (four question
  types), celebrations that repaint the shell, automatic birthdays,
  animated personal cards
- Role-scoped views (DG / directorate head / coordination / staff),
  issued accounts, email-invitation onboarding with a locked employment card

## Status and honest limits

This is the approved interactive model at a real address. It is static:
demonstration accounts, and state resets on reload. The agreed path to a
real deployment is a thin backend added around this file — persistence on
the QAGC Google Drive (decided 2026-08-20), real issued credentials, and
TOTP two-step — without changing what the reviewer already approved.

## Updating

The file is the source. Edit `app/index.html`, commit, push — GitHub Pages
redeploys within minutes.
